# ライセンス一元管理

企画設計書をもとにした、ライセンス管理画面の初期実装です。

## 起動方法

`index.html` をブラウザで開いてください。追加・編集・削除・返却したデータは、ブラウザの `localStorage` に保存されます。

`server.py` は SQLite ファイルを自動生成しません。SQLite を使うバックエンドが必要な場合は、既存のデータベースを用意してから起動してください。

```text
index.html
styles.css
app.js
schema.sql
```

## 実装済みの範囲

- ダッシュボード（ツール数、契約数、割り当て数、利用可能数）
- ツールの登録・編集・削除・検索
- ライセンスの登録・編集・削除・検索
- 利用者の登録・編集・削除・検索
- ライセンスの割り当て・返却
- ログイン／ログアウト（デモ認証）
- 契約数超過・重複割り当ての入力チェック
- 利用者CSV取込、利用者・ライセンスCSV出力
- 更新期限候補と操作履歴の表示
- 操作履歴
- レスポンシブレイアウト

デモログインは `admin@example.jp` / `demo1234` です。画面内のデータ処理は現在フロントエンドのみで、データはブラウザの `localStorage`、ログイン状態は `sessionStorage` に保存されます。デモ認証は本番用の認証ではありません。

`schema.sql` の MySQL/MariaDB スキーマと接続する場合は、後続工程で Laravel の API、サーバー側認証、権限チェック、CSRF対策、パスワードハッシュ化、トランザクション処理を追加し、`app.js` の localStorage 処理を API 呼び出しへ置き換えます。
