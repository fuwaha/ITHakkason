# ライセンス一元管理

企画設計書をもとにした、ライセンス管理画面の初期実装です。

## 開発サーバーで起動

ログインとアカウント登録をデータベースで行う場合は、リポジトリ直下で次を実行してください。

```powershell
C:/Users/81809/AppData/Local/Microsoft/WindowsApps/python3.11.exe .\server.py
```

ブラウザで <http://127.0.0.1:8000> を開きます。`license_manager.sqlite3` が自動作成され、初期管理者は `admin@example.jp` / `demo1234` です。

`index.html` を直接開く方法は画面確認用です。直接起動した場合はAPIに接続できないため、ログイン・アカウント登録は動作しません。

`server.py` は SQLite ファイルを自動生成しません。SQLite を使うバックエンドが必要な場合は、既存のデータベースを用意してから起動してください。

```text
index.html
styles.css
app.js
schema.sql
```

## 実装済みの範囲

- ダッシュボード（ツール数、契約数、割り当て数、利用可能数）
- ツールの登録・編集・削除・検索
- ライセンスの登録・編集・削除・検索
- 利用者の登録・編集・削除・検索
- ライセンスの割り当て・返却
- `users` テーブルに合わせた複数アカウントの登録・ログイン（email、password、name、role）
- 契約数超過・重複割り当ての入力チェック
- 利用者CSV取込、利用者・ライセンスCSV出力
- 更新期限候補と操作履歴の表示
- 操作履歴
- レスポンシブレイアウト

初期管理者のログインは `admin@example.jp` / `demo1234` です。登録画面から複数の一般利用者アカウントを追加できます。ツール、ライセンス、利用者、割り当て、操作履歴は `server.py` のAPI経由でSQLiteに保存されます。`localStorage` はAPIが利用できない画面の初期表示用にのみ残り、ログイン後は常にサーバーの最新データで更新されます。登録・編集・削除・割り当て返却は管理者だけが実行できます。ログインセッションはサーバー側トークンで管理します。

ダッシュボードには30日以内に更新期限を迎えるライセンス数と、期限切れがある場合の警告を表示します。

`server.py` は開発・検証用です。本番公開前にはLaravel等へ移行し、HTTPS、CSRF対策、ログイン試行制限、秘密情報の環境変数管理、DBバックアップ、権限チェックを追加してください。
