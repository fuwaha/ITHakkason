# ライセンス一元管理

企画設計書をもとにした、ライセンス管理画面の初期実装です。

## 起動方法

`index.html` をブラウザで開いてください。追加・編集・削除・返却したデータは、ブラウザの `localStorage` に保存されます。

```text
index.html
styles.css
app.js
schema.sql
```

## 実装済みの範囲

- ダッシュボード（ツール数、契約数、割り当て数、利用可能数）
- ツールの登録・編集・削除・検索
- ライセンスの登録・編集・削除・検索
- 利用者の登録・編集・削除・検索
- ライセンスの割り当て・返却
- 操作履歴
- レスポンシブレイアウト

画面内のデータ処理は現在フロントエンドのみです。`schema.sql` の MySQL/MariaDB スキーマと接続する場合は、後続工程で Laravel の API を追加し、`app.js` の localStorage 処理を API 呼び出しへ置き換えます。
